# Manual Testing Project – 50+ Test Cases

## Overview
This project demonstrates manual testing performed on multiple C programs.

## Programs Tested
- Palindrome Checker
- Quadratic Equation Solver
- Banking Transaction System
- Triangle Classification
- Student Grading System

## Testing Coverage
- Functional Testing
- Boundary Value Testing
- Edge Case Testing
- Negative Testing

## Key Findings
- Identified overflow issues
- Detected incorrect outputs due to rounding errors
- Found system crashes for invalid inputs
